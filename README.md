# 短信验证码转发

手机收到验证码短信后，直接推送到企业微信群机器人或邮箱。

```
手机短信 → 企业微信 / 邮箱
```

```
android/   安卓 App（Kotlin）
server/    可选的旧服务端，App 已经不再使用
```

只在自己的手机上使用。

## 安卓 App

需要 JDK 17 和 Android Studio。用 Android Studio 打开 `android/`，等 Gradle 同步（AGP 8.5 需要 Gradle 8.7 或更高），然后 Build → Build APK。

1. 安装后打开，允许接收短信、读取短信、读取手机状态、读取本机号码和通知。桌面名称是「码到」。
2. 企业微信群里添加群机器人，把 Webhook 地址填进 App。邮箱可以留空；要同时发邮件时，再填 SMTP 服务器、端口、发件邮箱、授权码和收件邮箱。QQ 邮箱是 `smtp.qq.com` / `465`，授权码在邮箱设置里开启 SMTP 后获取。
3. 点「保存并启动」，再点「发送测试」。企业微信里会出现一条平台为「测试」、验证码为 `123456` 的消息。

行为：

- 转发带验证码、校验码、动态码、动态密码、确认码、激活码、口令、verification、code、OTP、PIN 等字样的短信。整条就是一串 4 到 8 位数字，或很短且只有一串这样的数字，也会转发。长短信会合并。
- 除了短信广播，后台还会读取收件箱。有的手机不把验证码广播给第三方应用。页面上能看到最近一条短信和转发结果。
- 双卡从短信广播里读取 subscription id；读不到时再按卡槽号查，格式为 `SIM1(运营商)`。能读到本机号码时一并带上。
- 短信接收器是静态注册的，系统会唤醒 App。保存后会显示一条前台通知。已经填过 Webhook 或邮箱时，开机自动启动。
- 邮件一封发完再发下一封。QQ 返回 535 登录限制后，20 分钟内不再登录。其他网络失败最多重试 3 次。同一条短信成功发出后不会再发第二次。
- 目标是 Android 14（`targetSdk 34`）。这是自用侧载应用，前台服务类型是 `specialUse`，不保证能上架 Play。
- 小米、华为、OPPO、vivo 还需要手动允许自启动、电池设为无限制，并关闭「验证码保护 / 通知类短信拦截」。有的系统只把验证码短信交给系统短信 App。

Webhook 和邮箱授权码只保存在手机里，应用关闭了备份。

## iPhone 快捷指令

iOS 不允许 App 读取短信。快捷指令可以直接把短信发给企业微信，不需要自己的服务器：

1. 打开「快捷指令」→「自动化」→「+」→「信息」。
2. 「信息包含」填 `验证码`。需要的话再分别建 `校验码` 和 `code`。选择「立即运行」，关闭「运行前通知」。
3. 新建空白自动化，添加「获取 URL 内容」：
   - URL：企业微信群机器人的 Webhook 地址
   - 方法：`POST`
   - 头部：`Content-Type` = `application/json`
   - 请求体选 JSON，内容为：

```json
{
  "msgtype": "text",
  "text": {
    "content": "短信正文"
  }
}
```

`content` 里插入变量：快捷指令输入的发件人和内容。例如 `发件人：` + 发件人 + 换行 + `内容：` + 内容。

4. 保存后，用另一台手机给自己发一条含「验证码 123456」的短信。

要同时收到邮件，可以再加一个「发送电子邮件」操作，收件人填自己的邮箱，正文用同一段短信。部分 iOS 版本仍会要求确认后才发送或才运行自动化。双卡 iPhone 区分不了是哪张卡收到的。
